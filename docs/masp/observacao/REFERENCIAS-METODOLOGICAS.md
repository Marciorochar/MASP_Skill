# Referências metodológicas — Observação Universal v2

Adaptação autoral de princípios gerais. Links são fontes metodológicas, não atestados de coleta, certificação ou comprovação de eficácia do agente. Nenhum texto, template ou skill de terceiro foi reproduzido integralmente. Respeitar licenças e atribuição de cada origem.

| Fonte | Contribuição para este módulo | Limitação de uso |
| --- | --- | --- |
| [Lean Enterprise Institute — Gemba Walk](https://www.lean.org/lexicon-terms/gemba-walk/) | Observar a condição real e contrastar relatos com o contexto, quando há visita autorizada | Não declarar observação física sem presença no local; não obriga visitas |
| [ASQ — Check Sheet](https://asq.org/quality-resources/check-sheet) | Folha padronizada, definições operacionais, período e registro de eventos | Útil quando ocorrências podem ser registradas repetidamente; não se aplica a todo fenômeno |
| [ASQ — Seven Basic Quality Tools](https://asq.org/quality-resources/seven-basic-quality-tools) | Organização descritiva de distribuições, tendências e ocorrências | Selecionar ferramentas conforme dados e objetivo, sem conclusão causal prematura |
| [NIST/SEMATECH — Measurement Process Characterization](https://www.nist.gov/publications/nistsematech-engineering-statistics-handbook-chapter-2-measurement-process) | Repetibilidade, reprodutibilidade, estabilidade, calibração e incerteza em medições instrumentais | Não exigir ensaios metrológicos em problemas sem instrumentos |
| [CDC — Gather Credible Evidence](https://www.cdc.gov/evaluation/php/evaluation-framework-action-guide/step-4-gather-credible-evidence.html) | Planejamento da coleta, fontes, métodos quantitativos/qualitativos, qualidade, adequação e ética | Método de avaliação adaptado a observações MASP; não é regra normativa universal |
| [Superpowers — Systematic Debugging](https://github.com/obra/superpowers) | Princípios de reprodução, preservação de logs e inspeção de sintomas | Não migrar análise causal para a fase Observação |
| [Data Analytics — Analyze Data Quality](https://chatgpt.com/plugins) | Completude, validade, consistência, atualidade e relevância de dados quando instalada | Skill não é pré-requisito universal nem prova de medição |

**Autoria/licenças:** metodologia elaborada no MASP_Skill com referências citadas; documentação externa possui direitos e condições próprios. O uso de ideias gerais não autoriza reprodução extensiva de conteúdo protegido, imagens, templates ou código.

**Decisões locais:** categorias `FATO_VERIFICADO`/`RELATO_NAO_VERIFICADO`/`HIPOTESE`/`DESCONHECIDO`; Gate 02 e suas quatro chaves; modo rápido/aprofundado; JSON sidecar; avaliação por `PASS`/`BLOCKED`/`FAIL`. Essas regras são do projeto e não citações literais das fontes.
