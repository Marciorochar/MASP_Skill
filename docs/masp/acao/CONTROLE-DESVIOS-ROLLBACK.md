# Controle de desvios, parada e reversibilidade

| ID | Tarefa | Desvio/risco | Fonte | Stop/decisão competente | Responsável | Resultado | Pendência |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

- **Reversível:** procedimento de restauração, gatilho, aprovação e verificação, com status real.
- **Parcialmente reversível:** delimitar etapas e danos residuais.
- **Irreversível:** documentar ponto de não retorno, condição de parada anterior, riscos e contingência. Não registrar rollback completo impossível.
- **Falha/desvio:** parar com segurança, preservar fontes e acionar processo competente. Alteração de escopo retorna ao M04.
- **NOT_RUN** permanece não executado; não preencher resultados fictícios.
